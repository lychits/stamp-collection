# Лист памяти — коллекция почтовых марок

Личный филателистический каталог: фотографии марок, карточки выпусков,
поиск, фильтры и дашборд с диапазоном оценочной стоимости в рублях.

## Запуск

Нужны Node.js 22+ и pnpm 10+.

```bash
pnpm install
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/philately-collection dev
```

Откройте `http://localhost:5173`. В PowerShell переменные `PORT` и `BASE_PATH`
нужно задать через `$env:PORT` и `$env:BASE_PATH` перед командой запуска.

Проверка типов и сборка сайта:

```bash
pnpm --filter @workspace/philately-collection typecheck
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/philately-collection build
```

## Структура

- `artifacts/philately-collection/` — React + Vite, основной сайт и фотографии альбома.
- `lib/` — общие библиотеки рабочей области.
- `artifacts/api-server/` — исходная заготовка API; для текущего каталога запускать её не нужно.
- `research/` — исследование выпусков, источники и ограничения оценок.

## Данные и оценки

Ручные изменения карточек хранятся в браузере (`localStorage`). Они не входят
в этот репозиторий и не синхронизируются между устройствами.

Диапазон стоимости — ориентировочная сумма оценок карточек, а не подтверждённая
цена продажи. Пересчёт USD/RUB использует курс ЦБ через публичный сервис
[cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/); дата курса показана на дашборде.
Спорные атрибуции и ограничения сохранены в карточках и исследовании.

Секреты, зависимости, сборки и служебная история Replit не включены.
